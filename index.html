SIRE LINE

Eclipse — Sunday Silence

◆

1764年、一頭の栗毛馬が英国の競馬場を席巻した。
その名はEclipse——18戦全勝の不敗伝説。
以来222年、父から子へと受け継がれた血の系譜は
大洋を渡り、日本競馬の歴史を塗り替えるに至る。
21頭の名馬が紡いだ、父系の物語。

Generation I

Eclipse

1764

「Eclipse first, the rest nowhere」——18戦全勝の偉業を成し遂げた近代サラブレッドの始祖。その圧倒的な走りは競馬の歴史を根底から変えた。

Generation II

Pot-8-Os

1773

名は「Potatoes」の語呂合わせ。Eclipseの血を最も力強く次代に伝えた後継種牡馬であり、偉大な父系の礎を築いた。

Generation III

Waxy

1790

1793年エプソムダービー優勝。種牡馬としても傑出し、4頭のダービー馬を輩出した18世紀末を代表する名サイアー。

Generation IV

Whalebone

1807

1810年エプソムダービー優勝。小柄ながら力強い走りで知られ、19世紀の主要な父系の礎を築いた偉大な種牡馬。

Generation V

Sir Hercules

1826

アイルランド産の名馬。その名の通り強靭な体躯を持ち、種牡馬として多くの優駿を世に送り出した。

Generation VI

Birdcatcher

1833

アイルランドの快速馬。体に現れる独特の白斑は「Birdcatcher spots」として今日でもその名で呼ばれている。

Generation VII

The Baron

1842

1845年セントレジャーS優勝。後にフランスへ輸出され、欧州大陸における血統発展にも大きく寄与した。

Generation VIII

Stockwell

1849

「種牡馬の帝王（Emperor of Stallions）」——英国リーディングサイアー7回の金字塔。19世紀最高の種牡馬と称される。

Generation IX

Doncaster

1870

1873年エプソムダービー優勝。父Stockwellの偉大な血統を競走と繁殖の両面で継承し、次世代へと橋渡しした。

Generation X

Bend Or

1877

1880年エプソムダービー優勝。鮮やかな栗毛の美しい馬体で「黄金の馬」と称された、ヴィクトリア朝の名馬。

Generation XI

Bona Vista

1889

1892年2000ギニー優勝。父Bend Orの父系を確実に次代へ繋いだ重要な種牡馬。

Generation XII

Cyllene

1895

アスコットゴールドカップなど重賞を多数制覇。種牡馬として4頭の英ダービー馬を送り出した大種牡馬。

Generation XIII

Polymelus

1902

英国リーディングサイアー5回。20世紀初頭の英国競馬界に君臨し、近代血統の方向性を決定づけた大種牡馬。

Generation XIV

Phalaris

1913

競走成績は平凡だったが、種牡馬としてPharosとFairwayの二大系統を確立。現代サラブレッドへの影響は計り知れない。

Generation XV

Pharos

1920

仏・英でリーディングサイアーに輝いた名種牡馬。不世出の名馬Nearcoを送り出し、血統史に不朽の名を刻んだ。

Generation XVI

Nearco

1935

イタリアの英雄。14戦全勝——第二次大戦前に英国へ渡り、20世紀最大の影響力を持つ種牡馬に。現代サラブレッドの大半がこの馬に遡る。

Generation XVII

Royal Charger

1942

英国産の良血馬。北米に渡り種牡馬として成功し、Turn-toを通じて父系を新大陸に根付かせた架け橋的存在。

Generation XVIII

Turn-to

1951

アイルランド産、米国で活躍。種牡馬として新たなスピード血統の潮流を生み出し、米国競馬の血統地図を塗り替えた先駆者。

Generation XIX

Hail to Reason

1958

2歳時に9戦8勝の圧倒的強さを見せたが骨折により早期引退。種牡馬としてRoberto、Haloらを輩出し、父系を世界に広げた。

Generation XX

Halo

1969

米国の名競走馬にして名種牡馬。Sunday Silence、Devil's Bagなど数々のGI馬を世に送り出し、血統の黄金期を築いた。

Generation XXI

Sunday Silence

1986

1989年ケンタッキーダービー・プリークネスS優勝、米年度代表馬。日本に渡り空前絶後の大種牡馬として君臨。リーディングサイアー13年連続——日本競馬の歴史そのものを塗り替えた。

◆ ◆ ◆

Eclipseから222年——21世代にわたる父系の系譜は、
英国からアイルランド、イタリア、北米、そして日本へと渡り、
サラブレッドの歴史そのものを形作ってきた。
